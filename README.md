# نظام الحضانة الذكي — Full Stack

## التشغيل
Python 3.10+ مطلوب.

```bash
pip install -r requirements.txt
python app.py
```

ثم افتح: http://127.0.0.1:5000

- المدير: admin@nursery.local / 123456
- المعلمة: teacher@nursery.local / 123456
